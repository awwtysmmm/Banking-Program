# Banking Program 🏦

A simple **Banking Management Program** that simulates basic banking operations.Users can manage their account,check their balance,deposit money,withdraw funds,and perform other essential banking activities through an easy-to-use interface.

### Features

* 💰 Check account balance
* 💵 Deposit money
* 💳 Withdraw money
* 🏦 Manage basic account operations
* 🔐 Simple and user-friendly interface

### How It Works

The program allows users to interact with their bank account through a menu driven system.Users can select different banking operations,enter the required information,and receive an updated account balance.

This beginner friendly project is useful for practicing **variables,conditional statements,loops,functions,user input,and basic programming logic**.
